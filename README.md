# Mr English
Offline kids' English app (Teacher Shalabi). Lessons follow Top Grammar KG1 & KG2.
Voice lines: `audio/<id>.mp3`, list in `audio/manifest.json` / `audio/manifest.tsv` (regenerate with `node build_manifest.js`).
